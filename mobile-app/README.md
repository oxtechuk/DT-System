# تطبيق DDT Working Space — Native Mobile App (Android & iOS)

تطبيق موبايل أصيل (100% Native - ليس WebView) مبني باستخدام **React Native / Expo** ومصمم للقبول المباشر في متجري **Google Play** و **Apple App Store**.

---

## 🚀 1. التشغيل والتجربة الفورية على هاتفك (Expo Go)

1. حمّل تطبيق **Expo Go** مجاناً من متجر Google Play أو App Store على هاتفك.
2. افتح منفذ الأوامر في مجلد التطبيق:
   ```bash
   cd mobile-app
   npm start
   ```
3. افتح كاميرا الآيفون أو تطبيق Expo Go على الأندرويد وامسح كود الـ QR الظاهر في الشاشة؛ سيعمل التطبيق فوراً على هاتفك بأداء Native كامل!

> **ملاحظة لاختبار الـ API من الموبايل:**
> في ملف `src/config/api.ts`، قم بتغيير `127.0.0.1` إلى عنوان الـ IP المحلي لجهاز الكمبيوتر المتصل بنفس شبكة الـ Wi-Fi (مثال: `http://192.168.1.50:8000/api/v1`).

---

## 📦 2. استخراج ملف الـ APK لتجربته على هواتف أندرويد مباشرة

لاستخراج ملف **APK** جاهز للتثبيت على أي هاتف أندرويد دون الحاجة لجهاز أندرويد استوديو، قم بتشغيل:
```bash
cd mobile-app
npx eas build -p android --profile preview
```
سيقوم سيرفر Expo السحابي ببناء ملف الـ APK وإعطائك رابط تحميل مباشر له.

---

## 🏪 3. بناء ملفات الرفع لمتاجـر التطبيقات الرسمية

### أ) متجر Google Play Store (حزمة AAB):
```bash
cd mobile-app
npx eas build -p android --profile production
```
يستخرج ملف **Android App Bundle (.aab)** المعتمد للرفع على Google Play Console.

### ب) متجر Apple App Store (ملف IPA):
```bash
cd mobile-app
npx eas build -p ios --profile production
```
يقوم ببناء ملف **.ipa** ورفعه إلى حسابك في Apple Developer عبر السحابة دون الحاجة لجهاز Mac.

---

## 📱 مميزات التطبيق المطابقة لمعايير أبل وجوجل:
- ✅ **واجهات أصيلة 100% (Native C++ / Fabric):** تضمن اجتياز البند 4.2 لأبل وتمنع الرفض.
- ✅ **أزرار تحكم بالكمية مع لمسات اهتزازية (Haptic Feedback).**
- ✅ **بوابة خاصة بالمدرسين والعمولات:** تظهر فقط للمدرسين في القائمة السفلية.
- ✅ **بطاقة الولاء الرقمية (5 زيارات):** لحساب الزيارات تلقائياً واستلام مشروب مجاني.
- ✅ **جلسة مساحة العمل الحالية:** عداد زمني لاحتساب مدة الجلوس وحساب الاستهلاك لحظياً.
- ✅ **خاصية حذف الحساب (Delete Account):** مطابقة لشروط الخصوصية الإلزامية لمتجر Apple.
